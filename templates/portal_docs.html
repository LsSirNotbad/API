新手使用指南

先了解接口参数和返回结构，再用沙盒熟悉结果，最后在需要时发送真实测试。真实测试与本地模拟彼此独立，你可以按自己的节奏完成接入。

进入接口中心
1

选择接口并阅读文档

从接口目录进入独立详情页，查看入参名称、类型、是否必填、默认值，以及出参和响应示例。

2

先用沙盒验证流程

沙盒只在浏览器本地生成模拟结果，不请求目标接口、不消耗额度，适合检查参数填写与理解返回结构。

3

生成代码或真实测试

可复制 cURL、JavaScript Fetch、Python requests 示例；需要验证线上服务时，再单独点击“发送真实测试”。

凭证安全：网页只展示掩码 Token，所有生成的代码统一使用 YOUR_TOKEN 占位。请在自己的安全环境中替换，不要分享真实密钥。
QUICKSTART

快速接入与代码生成

指定一个接口，即可进入代码生成区。系统会带上当前填写的参数，生成可复制示例，但不会把真实 Token 写入代码。

选择要接入的接口

不会自动选择第一个接口。选择后进入详情页的代码区域，可继续调整参数和语言。

接入只需三步

  1. 1
    在代码区选择 cURL、JavaScript Fetch 或 Python requests，并点击“生成代码”。
  2. 2
    复制代码，将 YOUR_TOKEN 替换为你自己的 Token；真实密钥不会出现在页面代码中。
  3. 3
    先检查请求路径和参数，再在你的开发环境运行。文档中的响应示例不是实时响应。
